How the pieces connect

Follow one order through a stack we built.

  1. A buyer presses Pay on your storefront.
  2. The API checks who they are and what they may do.
  3. The payment goes through and the order is saved.
  4. A background job emails the receipt.
  5. The screen confirms the order. Every step is code you own.

Questions

Asked before every project.

Which stacks do you work in?

For UI: React, Next.js, Vue, Nuxt and Svelte. For backends: Node.js, Python, Go and PHP, with PostgreSQL, MySQL or MongoDB. If your team already has a stack, we work in it.

Can you put a UI template and a backend template together?

Yes. Our full-stack starters already are. With a setup package we connect any UI template to any backend template and deploy them together.

Do we own the code?

Templates come with a commercial licence for one product, and you can change anything. On a custom build the repository is transferred to you at launch.

Can you work on our existing product?

Yes. Many custom builds extend an app a client already runs: a new admin panel, an API for a mobile app, or an integration with another system.

What happens after launch?

Templates get 12 months of updates. Custom builds get 90 days of fixes. After that, a care plan covers updates, monitoring and small changes.
