Questions

Asked before every purchase.

Do I need a developer to use a template?

Not for copy, images and colours. The guide shows where each one lives. For new page types or integrations, choose the launch package or a care plan and our team does it.

Where can I host the site?

Anywhere that serves static files, including GitHub Pages, Netlify, Vercel or your own server. There is nothing to install on the server.

Can I use one template for several websites?

Each licence covers one company website. Agencies and groups building several sites can ask us for a multi-site licence.

What does support cover?

Questions about the template, bug fixes and updates for 12 months. Changes to your content and design are part of the launch package and the care plan.
